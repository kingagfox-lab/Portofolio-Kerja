Fonts are loaded from Google Fonts via CDN `<link>` tags in each page's
`<head>` (Poppins + JetBrains Mono), so no local font files are required.
If you need a fully offline copy, download the .woff2 files from
https://fonts.google.com and reference them here with an `@font-face`
rule in assets/css/main.css.
